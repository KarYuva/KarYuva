# KarYuva — راهنمای سایت

## ساختار پوشه
- `index.html` — نقطه شروع سایت
- `css/style.css` — ظاهر و رنگ‌ها
- `js/config.js` — ⭐ تنظیمات: شماره‌ها، تلگرام، روبیکا، ایمیل، فرم
- `js/app.js` — متن‌های سه زبان و منطق سایت
- `assets/` — لوگو و فاویکون
- `robots.txt` و `.nojekyll`

## آپلود در گیت‌هاب
1. ریپازیتوری جدید بسازید (مثلاً `karyuva`).
2. محتوای پوشه را (نه خود پوشه را) آپلود کنید؛ `index.html` باید در ریشه باشد. فایل `.nojekyll` را هم فراموش نکنید.
3. Settings ← Pages ← Deploy from a branch ← `main` و `/ (root)` ← Save.
4. آدرس: `https://USERNAME.github.io/karyuva/`

## چیزهایی که باید جایگزین شوند (js/config.js)
- `rubika`: لینک روبیکا (تا خالی است دکمه‌اش غیرفعال می‌ماند)
- `email`: ایمیل (خالی = کارت ایمیل نمایش داده نمی‌شود)
- `formUrl`: لینک فرم اطلاعات متقاضی (خالی = پیام «فرم هنوز متصل نشده»)
- شماره‌ها، واتس‌اپ و تلگرام با اطلاعات شما پر شده‌اند.

## نکات
- مسیرها با هش کار می‌کنند: `#fa-home` ، `#en-about` ، `#tr-contact`
- عکس‌های واقعی شهرها را در `assets/` بگذارید تا اضافه شوند.
- متن‌های انگلیسی و ترکی را قبل از انتشار یک نفر بومی بازبینی کند.
